# Architecture Decision Records (ADR)

Εδώ καταγράφονται οι σημαντικές αποφάσεις για το site: τι αποφασίστηκε, γιατί, ποιες άλλες
επιλογές υπήρχαν και τι κόστος έχει η απόφαση. Ένα αρχείο ανά απόφαση, με αύξοντα αριθμό.
Ένα ADR δεν αλλάζει μετά· αν αλλάξει η απόφαση, γράφεται νέο ADR που «αντικαθιστά» το παλιό.

| # | Απόφαση | Κατάσταση | Ημερομηνία |
|---|---|---|---|
| [0001](0001-arxiki-se-plegma-bento.md) | Αρχική σελίδα σε πλέγμα «bento» με ζωντανό περιεχόμενο | Αποδεκτή | 21/10/2026 |
| [0002](0002-politiki-asfaleias-headers-csp.md) | Πολιτική ασφαλείας: HTTP headers και CSP χωρίς 'unsafe-inline' στα scripts | Αποδεκτή | 22/10/2026 |
| [0003](0003-selides-agonon.md) | Μία σελίδα για κάθε αγώνα, με αντίστροφη μέτρηση, .ics, καιρό εκκίνησης και ρυθμό | Αποδεκτή | 26/10/2026 |

## Πρότυπο για νέο ADR

```markdown
# ADR 000N: <Τίτλος>

- **Κατάσταση:** Προτεινόμενη | Αποδεκτή | Αντικαταστάθηκε από ADR 000X
- **Ημερομηνία:** <ημερομηνία>
- **Υλοποίηση:** <PR>

## Πλαίσιο
Ποιο πρόβλημα λύνουμε και τι ισχύει σήμερα.

## Επιλογές που εξετάστηκαν
Οι εναλλακτικές, με υπέρ και κατά.

## Απόφαση
Τι επιλέχθηκε και γιατί.

## Συνέπειες
Θετικές και αρνητικές, μαζί με ό,τι πρέπει να προσέχουμε από εδώ και πέρα.
```
